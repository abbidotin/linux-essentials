| Command | Function                                    | Useful feature                           |
| ------- | ------------------------------------------- | ---------------------------------------- |
| `touch` | Creates an empty file or updates timestamps | Can create multiple files                |
| `mkdir` | Creates directories                         | `-p` creates parent directories          |
| `rmdir` | Removes empty directories                   | Only works on empty directories          |
| `cp`    | Copies files/directories                    | `-r` recursive                           |
| `mv`    | Moves or renames files/directories          | Used for both operations                 |
| `rm`    | Removes files/directories                   | `-r` recursive, `-f` force               |
| `file`  | Determines a file's type                    | Identifies content type                  |
| `stat`  | Displays detailed file information          | Shows permissions, ownership, timestamps |
| `ln`    | Creates links                               | `-s` creates symbolic link               |
