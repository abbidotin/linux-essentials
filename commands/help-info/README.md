| Command   | Function                                   | Useful feature      |
| --------- | ------------------------------------------ | ------------------- |
| `man`     | Opens the manual page for a command        | `man ls`            |
| `info`    | Displays detailed GNU documentation        | `info coreutils`    |
| `whatis`  | Gives a short description of a command     | `whatis ls`         |
| `apropos` | Searches manual descriptions for a keyword | `apropos network`   |
| `help`    | Shows help for shell built-ins             | `help cd`           |
| `command` | Identifies or executes a command           | `command -v python` |
| `type`    | Shows how the shell interprets a command   | `type cd`           |
| `which`   | Shows the location of an executable        | `which python`      |
