| Command   | Function                               | Useful feature                                  |
| --------- | -------------------------------------- | ----------------------------------------------- |
| `pwd`     | Displays the current working directory | Shows absolute path                             |
| `ls`      | Lists files and directories            | `-l` detailed, `-a` hidden, `-h` human-readable |
| `cd`      | Changes the current directory          | `cd ..` parent, `cd ~` home                     |
| `clear`   | Clears the terminal screen             | Keeps terminal output clean                     |
| `echo`    | Displays text or variable values       | Useful in scripts                               |
| `history` | Displays previously executed commands  | Commands can be reused                          |
| `alias`   | Creates command shortcuts              | `alias ll='ls -l'`                              |
| `unalias` | Removes an alias                       | Removes a defined shortcut                      |
