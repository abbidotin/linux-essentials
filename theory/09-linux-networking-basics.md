# Linux Networking Basics
Linux provides networking capabilities that allow systems to communicate with other devices and networks.

## Network Interfaces
A **network interface** is the point through which a Linux system connects to a network.
Common types include:
* Ethernet
* Wireless
* Virtual interfaces

A system can have multiple network interfaces.

---

## IP Address
An **IP address** identifies a device or network interface on a network.
Linux systems can use:
* IPv4
* IPv6

IP addresses allow systems to communicate with other devices across a network.

---

## Network Configuration
Network configuration defines how a Linux system communicates with a network.
It can include:
* IP address
* Subnet mask
* Default gateway
* DNS servers

---

## Routing
**Routing** determines how network traffic travels from one network to another.
A **default gateway** is used when traffic needs to reach a destination outside the local network.

---

## DNS
**DNS (Domain Name System)** translates human-readable domain names into IP addresses.
For example:
```text id="b5m6r8"
example.com → IP address
```

DNS allows users and applications to access network resources using domain names instead of numerical IP addresses.

---

## DHCP
**DHCP (Dynamic Host Configuration Protocol)** automatically provides network configuration information to devices.
It can provide:
* IP address
* Subnet mask
* Default gateway
* DNS server information

This simplifies network configuration.

---

## Network Services
Linux can provide various network services to other systems.
Examples include:
* DNS
* DHCP
* SSH
* File sharing
* Web services
* Mail services

---

## Network Troubleshooting
Linux provides networking tools and utilities for identifying connectivity and configuration problems.
Network troubleshooting can involve checking:
* Network interfaces
* IP configuration
* Routing
* DNS resolution
* Network connectivity

---

## Key Takeaways
* Linux supports wired, wireless, and virtual networking.
* IP addresses identify systems and network interfaces.
* Network configuration determines how a system communicates.
* Routing determines where network traffic is sent.
* DNS translates domain names into IP addresses.
* DHCP automatically provides network configuration.
* Linux can provide various network services.
